# NovelAgent：Windows 作者使用指南

这是本机单用户的候选版。首次安装需要 Windows 上的 Python 3.12 和可下载依赖的网络（已有离线依赖源也可以）。ZIP 不含 Python、模型账户、私钥或书稿。

1. 将整个 ZIP 解压到新的固定目录。不要覆盖旧程序、作品或备份。在这个有 `启动创作工作台.bat` 的目录打开 PowerShell，运行 `py -3.12 scripts/setup_environment.py --runtime-only`。看到 `Project environment ready` 表示安装完成。如果没有 `py` 命令，使用已安装的 Python 3.12 解释器代替 `py -3.12`。
2. 双击 `启动创作工作台.bat`。浏览器打开书架后创建作品，或选择已有作品所在的目录导入。首次体验请用测试作品。从 ZIP 正常启动时，新作品默认放在 `%LOCALAPPDATA%\NovelAgent\books`，换程序包不会覆盖书稿。若启动时指定了作品目录，则使用指定目录。日常启动不需要再执行安装命令。要切换版本，先关闭旧工作台，避免浏览器复用旧实例。
3. 新书只填书名就能创建。如果已确定人物或背景，可以填入「已确定的开篇设定」；没有把握就留空。打开「继续写作」，填写本章的标题、核心事件、必写节拍和结尾悬念，保存章纲后确认本章意图。章纲记录的是计划，只有审稿时接受的事实才会进入后续章节。
4. 有手稿就点「导入已有稿件」，编辑并保存，再选「自行审阅事实（不调用模型）」。对照正文原句补充并接受事实；首次出现的人物或地点可在下方声明。也可以配置模型和本章限额后使用在线生成或提取。核对预览，通过后点「确认发布本章」。**只保存草稿，不会写入正式正文。**
5. 关闭再打开工作台，回到第一章能看到正式稿；在第二章展开「写这一章时，会带上哪些已确认的事实？」即可核对开篇设定和上一章接受的事实及原句。旧版建立的作品保留原有写作方式，不会因为打开了新版本就被转换。

**从旧版切换或恢复：** 保留原 ZIP、旧环境、作品和工作台数据。在旧版工作台中先备份并核验可恢复性；需要恢复时用当时的程序版本及匹配归档，按工作台提示预览、选新目录并确认。不要用新 ZIP 覆盖唯一副本，也不要把换回旧程序当成数据回滚。首次安装验证与跨版本恢复是不同的事情。

## 在生成前估算费用

在章节页确认写作意图后，点「估算这次正文费用」。不需要先开预算，估算也不发送模型请求。修改目标或备注后，需重新确认。费用估算是可选项；不登记价格也可以按本章的调用、token 与时间限额生成。

要显示美元金额，在程序目录用工作台的 Python 运行 `python -m workbench.generation_price --model 模型名 --as-of YYYY-MM-DD --input-rate 普通输入单价 --output-rate 输出单价 --input-tier-limit 输入档位上限`，仅在账单以美元计价时，将参数换成自己服务商的报价，两个单价单位均为每百万 token。价格只存本机；换模型、密钥、地址或解压到新的程序目录后应重新核对并登记。同一密钥更换渠道或单价改变时也请重新登记。

页面按本章实际准备发送的内容估算输入，展示不同输出长度下的费用。估价只覆盖一次正文请求，不含缓存差价、其他步骤或额外尝试，也不启用或提高预算。若超时而未收到完整正文，对照服务商记录的时间、模型和请求方式核对费用；本地没收到完整回执不代表免费。
