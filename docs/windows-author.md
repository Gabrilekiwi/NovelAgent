# NovelAgent：Windows 作者使用指南

这是本机单用户的候选版。首次安装需要 Windows 上的 Python 3.12 和可下载依赖的网络（已有离线依赖源也可以）。ZIP 不含 Python、模型账户、私钥或书稿。

1. 将整个 ZIP 解压到新的固定目录。不要覆盖旧程序、作品或备份。在这个有 `启动创作工作台.bat` 的目录打开 PowerShell，运行 `py -3.12 scripts/setup_environment.py --runtime-only`。看到 `Project environment ready` 表示安装完成。如果没有 `py` 命令，使用已安装的 Python 3.12 解释器代替 `py -3.12`。
2. 双击 `启动创作工作台.bat`。浏览器打开书架后创建作品，或选择已有作品所在的目录导入。首次体验请用测试作品。日常启动不需要再执行安装命令。要切换版本，先关闭旧工作台，避免浏览器复用旧实例。
3. 选定作品和章节，核对章纲及上一章的状态。在线生成需要先在本机配置模型服务；具体配置字段见 `.env.example`，工作台不会向你索取密钥。未配置、预算不明或只想练习时，不要点付费生成。对已满足审核条件的章节，可以在章节页确认意图后导入已有稿件、编辑并保存草稿。
4. 准备入稿时，在工作台处理待办、核对新增事实及引文，然后预览并确认提交。**保存草稿不会发布正文。** 重新打开工作台，确认看到同一份草稿或正式稿，再决定是否开始下一章。调用超时先看待办和历史，不连续点击重试。

**从旧版切换或恢复：** 保留原 ZIP、旧环境、作品和工作台数据。在旧版工作台中先备份并核验可恢复性；需要恢复时用当时的程序版本及匹配归档，按工作台提示预览、选新目录并确认。不要用新 ZIP 覆盖唯一副本，也不要把换回旧程序当成数据回滚。首次安装验证与跨版本恢复是不同的事情。
