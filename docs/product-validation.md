# Windows 本地自用：怎样算验收通过

普通作者能在官方工作台独立选书，按已批准的章纲生成草稿，处理待办，编辑、审阅并提交正式正文。退出工作台再打开，能找到同一份正式稿，并在开始下一章时读到已确认的事实。写章和恢复过程中不需要别人代跑命令、修改数据库或搬运稿件。

实际试用时记录哪一步需要帮助、改稿花了多久、遇到的事实错误，以及费用能否查清。遇到调用结果未知，先保留草稿和原预留，核对后再决定是否续试；工具检查通过不等于模型实际写作质量通过。

一章试用可以验证基本流程，不能证明长篇质量稳定。两个十章批次和九维打分只用于可选实验，不是正式上线门槛。候选版、自动测试通过、作者独立验收通过是三个不同的结论。
