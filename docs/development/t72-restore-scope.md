# T7.2 恢复副本启用前隔离

验收日期：2026-09-14。此处只验收恢复副本的只读访问边界，不代表实际解包、新物理绑定或同机写入资格交接已经完成。

`restore_scope.py` 在工作台数据库初始化、作品加载和 worker 构造前读取 SQLite 内登记与独立凭据。两者必须一致，且数据库、父目录、作品目录物理绑定仍有效。恢复意图存在但登记缺失，或凭据删除、损坏、绑定变化，都阻止普通启动。启用前完整数据库保留，HTTP 只允许目标作品与其记录，未知入口默认拒绝；SQL 写事务、自动导入、启动恢复和任务领取停用。

界面显示“恢复副本尚未启用，当前只供核对资料”，隐藏维护、备份、新建和导入入口。作品页中的部分生产导航仍保留，写请求由服务端拒绝；这不是完整恢复向导。内部只读 SQL 检查仍能读取整库，隔离承诺针对工作台入口与目标登记/任务服务，不宣称 SQLite 行级读取权限。

验证：

- 新增 13 个不同用例。与数据库、作品和维护启动组合，29 通过、14 子测试通过，session 12288 exit 0；证据 `.tmp/stage-f-t72-scope-first.xml`。
- 工作台、任务、静态契约、维护 API 回归 75 通过、1 跳过，session 93262 exit 0；跳过为既有 Windows 创建文件软链接权限不足（WinError 1314），证据 `.tmp/stage-f-t72-scope-regression.xml`。
- 隐藏误导操作入口后静态契约 23 通过，exit 0；证据 `.tmp/stage-f-t72-scope-static-final.xml`。
- Chrome page 10 使用独立合成严格模式样书、两个实际登记作品、队列任务与草稿。原生进入目标作品正常 200；其他作品直接地址 409 并显示隔离原因，未显示另一作品内容；返回目标并整页刷新后 7 个 API 请求均 200。维护写请求 409 符合只读约束，随后隐藏该操作入口。控制台只有预期拒绝请求错误，无额外脚本错误。
- 浏览器前后 9 个合成书文件清单与哈希完全相同，数据库逻辑摘要相同。server 77332 / PID 25080 已终态退出（Ctrl-C exit 1），38889 无监听。证据 `.tmp/t72-scope-browser-evidence.json` 与 `.tmp/t72-scope-browser-after.json`。

夹具直接安装恢复限制，没有执行归档恢复；0 本地模型替身调用、0 真实 Provider 调用、0 真实作品写入。T7.1 新增验收计数仍为 405，T7.2 本组件新增 13；阶段 D、F 以及完整 A–F 目标均未完成。

后续：先从完整核验计划实际解包到独占新目录，在任何数据库字节写入前持久化恢复意图；然后实现历史只读映射、新物理控制、目标 SQL 重绑定、持续的其他作品隔离和同机资格交接。只有最终格式的新副本重启与下一章完整提交通过后，才可声明完整恢复认证。
