# T8.1：同模型配对验证执行准备

日期：2026-11-07。状态：离线准备，未授权、未开始、无结果。本文件落实主计划T8.1，不变更其门槛，也不授权T8.2。

## 开始前逐项核实

使用同目录`t81-validation-record.template.json`复制出本次独立记录，填写实际证据，不在模板中填写假成绩。当前模板的作品、输入和限额为空，尚不能执行真实验证。

1. 核实当前构建的T4.2、相关T5.2、T7.1验收证据及适用范围，记录源码、依赖锁、质量策略版本。历史构建通过、代码存在和跳过测试都不能代替该核实。
2. 由实际受支持流程准备隔离验收工作区，核验真实Strict资格、作品身份、来源与恢复能力。记录当时最新正式章节和状态；不固定旧章号，不手工造资格或修改原作品。两分支不能争写同一正式作品。
3. 用户独立明确Provider、端点、金额上限及币种、阅读人员与安排。`claude-opus-5-5`是用户指定的当前配置，尚无真实兼容结果；不能据名称假定端点支持或套用其他型号价格。
4. 冻结每个阶段的调用次数、输入/输出token、重试和金额限额。按实际计费口径核实价格来源、生效时间、缓存及其他收费项、可信输入上界和预留规则。兼容检查、失败、重试、提取、质量检查均计入阶段及总额。未知费用保留未知；无法给出可信上界时不启动金额受控验证。
5. 把上述具体输入、限额和阅读安排形成可审阅记录后取得本阶段明确授权。当前工程任务继续进行，不因本模板生成而视为获授权。

## 有限兼容、一章完整流程、三个配对任务

先完成有限Provider兼容检查，再完成一章逐章流程，核对生成、事实检查、作者审核、正式提交、下一章读回及全部调用费用。两项默认均不纳入配对统计，消耗仍计入本阶段总额；若要纳入，必须在任何调用前记录决定。

兼容检查或一章流程失败时，保留失败、调用和费用，先定位问题；不跳过前置步骤直接扩大到三个配对。无法解释的调用保留原证据，不自动重发。

三个任务编号固定为P1、P2、P3，每个任务各有manual和workbench两分支。运行前记录每对相同的章意图、上下文材料、正式起点、模型/端点、计费设置和输出边界的哈希。工作台使用逐章流程；对照由作者手工管理同一模型。两者采用各自正常操作，保存实际提示及补充信息，不能为其中一支额外提供另一支没有的剧情信息。

配对任务开始时，两分支都从该对冻结的共同起点取材。某分支的结果不得进入同一对另一分支的上下文。后续任务若依赖前章，应在开始前明确共同前章取自何处；否则两分支历史分叉会使配对失效。真实写入只发生在经过核验的隔离工作区。

预先随机并记录每对的操作先后，尽量平衡两种顺序；三对无法完全平衡，保留操作者学习和顺序影响。操作者无法盲化。本轮不混入故障注入、自动模式或异常接管样本。

## 人工计时

每个分支记录实际开始/结束时间及逐段时长，主动操作与等待分开。主动段使用以下类别：章意图与上下文准备、提示及界面操作、正文编辑、事实核对、排错恢复、其他。正常重复点击、复制整理及修正操作也计入，不只记录编辑器时间。

一次只能计入一个主动段。模型等待另记等待段；等待期间如果开始其他验证操作，应结束等待段或明确扣除重叠，不能重复加总。中断保存已有段，续接新增段；未知时间填null并解释，不能填0。工作台的服务器执行计时和“作者等待”字段不能当成人工阅读或主动操作时间。

正式记录同时保留正文编辑时长、全部主动时长、模型等待和端到端历时。配对收益比较使用全部主动时长；费用包括该分支所有尝试，失败与放弃仍占预定样本位置。

## 阅读和评分

每份保存首个原稿、所有修改稿、最终稿及对应哈希。主比较对象为最终可用稿，首稿单独评分并保留修改负担；两者不混合求均值。该选择在实际运行前冻结。

由不参与生成操作的读者阅读时，使用随机编号与随机顺序。评分包只含中性编号、共同章意图和必要上下文、正文；不显示模型、分支、文件来源或处理报告，不修改正文来隐藏风格线索。编号映射另存于非评分包位置，全部评分提交前不揭盲。若读者参与过生成或认出来源，记录该限制，不能称为独立盲评。

九维沿用`workbench/cohorts.py:SCORE_DIMENSIONS`：情节推进、连续性、人物一致性、世界观一致性、文笔质量、节奏、对话、章末钩子、整体可用性。人工分与模型分分开。每维使用1–5分整数：1为不可用，2为需大改，3为可用但需明显修改，4为仅需少量修改，5为可以直接采用。读者在评分前确认锚点；每项低分和严重缺陷附原文位置及依据。

严重事实缺陷包括与冻结权威材料矛盾、人物身份或关系错置、无法解释的时空/数量/物品变化等足以改变剧情结果的问题。一般措辞偏好不自动列为严重事实缺陷。严重项单列，不被九维平均或其他章节高分抵消；争议保留原判和复核理由。

## 汇总与退出

固定分母为三对，先列每对的九维均分、整体可用性、严重缺陷、主动时间、等待时间、总费用及失败原因，再报告三对汇总。缺稿、缺评分、未知费用或缺计时保留缺失，不以0补值、不删样本或另换任务凑通过。

每个任务的九维均分按九个等权人工分计算；同一分支的汇总为三个任务均分的等权平均。整体可用性单独取三个对应评分的平均；主动用时与费用分别求和。不按正文长度加权、不将原稿与最终稿或模型分混入人工均分。若有多个读者，运行前先固定读者及等权汇总方法，不能看到结果后挑选评分。

按主计划判断方向：无严重事实缺陷；工作台人工九维及总体可用性汇总不低于对照；三个工作台任务的主动用时之和低于三个对照任务之和；全部消耗在授权范围内。30%节时只报告观察值，不设为新增硬门。即使汇总满足，也必须说明个例退步、操作顺序、盲化限制和三个样本的适用范围。

结果不清楚时先处理审核负担、质量或成本问题。任何影响冻结条件的代码、模型、价格、输入或评分规则变化，应另建记录并保留本轮失败及花费，不覆盖本轮结果。T8.1通过后仍须独立安排T8.2的预算和阅读，不能自动启动二十章验收。
