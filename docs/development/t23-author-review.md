# T2.3 作者事实审阅实现

2026-09-10。按最终执行版1.0推进，当前代码在工作树。此记录仅覆盖T2.3，不表示完整阶段C或稳定生产版完成。

## 实现

- 七类事实直接读取后端同源payload契约，以中文字段、数值、实体/本章事件选择器及可增删数组行编辑。任意状态值使用文字、数值、是或否、列表和对象字段控件，无JSON编辑框。新增数值留空，枚举和布尔需明确选择；既有零、false、null和嵌套值保持原值。
- 正文在事实旁展示，可定位准确引用；显示已知初始值，缺失值提示补充。原始模型建议从绑定的不可变提取记录重新核验，作者编辑后仍可展开对照，不把当前编辑内容当作原稿。
- 现有PUT支持作者新增卡，服务器强制author来源和编辑标记。已存卡不能物理移除或换来源；拒绝保留记录。仅未保存的新增表单可撤回。
- 批量接受/拒绝只作用于作者选中且当前可见的项，点击后明确确认；初始无默认选中。空提取不再宣称正文没有事实，要求作者核对、补充或明确确认。
- 身份声明/称呼复用及六类缺失初始情况有独立表单，保存按钮表达作者决定，原因必填。使用审核revision CAS；保存补充保留尚未保存的事实编辑，未保存补充时不能锁定整组审核。
- `GET /api/fact-reviews/{id}/editor-context`返回本次原文、原模型建议、同源契约及支持能力。Reviewed3的实体目录和基线来自实际可信状态；旧路径明确不支持新补充。客户端不能提交这些派生状态作为写入权威。
- 事实更新事务内保存before/after修订快照；旧记录不补造历史。读取核验哈希、来源、修订连续性与最终事实集合。原始提取损坏或历史损坏明确拒绝。
- 改稿使旧决定过期，仍保留旧原文和原建议；确认后不可编辑。输入异步返回受当前路由、草稿和修订限制，保存中禁用表单避免迟到响应覆盖输入。
