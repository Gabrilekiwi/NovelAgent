# 工作台受控续试与草稿操作验证（2026-11-17）

用户认可第64章候选可作为正式章节基础后，同意将一次续试接入工作台，并验证改稿、保存、重新打开。本轮已经完成该范围，没有追加真实模型调用，也没有提交正式章节。

## 使用入口与行为

关闭旧工作台后双击仓库根目录的 `试用当前工作台.bat`，使用当前工作区版本和原工作台数据目录。默认 `启动创作工作台.bat` 在工作区有修改时可能打开已提交的旧界面；新的试用入口明确传入 `--use-working-tree`。如果旧实例尚在运行，实例保护仍会打开旧实例，因此先关闭旧窗口。

符合条件的不确定结果下方显示“允许再试一次”。第一次确认只保存许可，既不发送请求，也不释放旧占用；刷新后继续显示“开始这一次续试”。第二次确认才发送指定的同章、同意图请求。许可绑定唯一候选，重复请求只读取原结果，不能得到第二次机会。已有其他入口签发的许可不改签、不重复授权。

原请求的未知费用与完整预留保留，所有新调用仍受原总限额保护。预算、章意图、来源证据变化或无本机写资格时拒绝操作。普通“生成新候选”不能利用风险放弃绕过冻结预算。批次和修复不走这个单章入口。

完成后可编辑并保存工作台草稿；重开页面及重启服务后读取已保存版本。两页同时编辑时，旧版本保存返回冲突且保留本页文字。页首区分“可续试一次”“可编辑草稿”和预算限制，不把可用草稿显示为完全不能操作。
