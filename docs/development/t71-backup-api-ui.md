## 已实现

三个 POST 路由使用专门的快照准入，保留全局本机会话、Host、Origin 校验。快照许可在线程调度之前同步取得，通过 shield 与强引用任务集合持有，直到真实工作结束。来源文件锁上下文只借用许可，ZIP 完成后独立校验及最后发布 completion.json 期间仍不能退出维护。应用关闭等待后台任务完成再释放实例锁。

页面显示作品范围、总量、数据库、保存位置与排除数量，说明数据库包含其他作品登记信息。先预览才能保存；切换作品、维护操作改变、请求失败或退出维护会清空过期预览。校验失败覆盖先前的成功标记；刷新页面可以重新发现并校验归档。所有成功状态仍为 diagnostic / recoverable=false，不开放恢复按钮。
