## 行为与证明

实际公共首次登记得到的 V2 机器资格，在旧书 1.0/2.0 升级至 reviewed 3.0 后，允许使用登记后、升级前保存的原归档。升级后的新归档也必须核对原升级，不能仅凭当前机器代际或相同登记 ID 推断历史。

新 `machine_restore_handoff_v5` 保存归档登记、实际升级意图及完成凭据、完整事务清单与发布回执，以及有序的升级前/后回退链。核对保持原作品/物理绑定、登记、witness；仅经实际升级证明允许身份摘要改变。所有原机器文件与实际升级事务文件在 live 续接时重验；缺失不扫描、不重新登记、不修复。上限为递归 16、升级及回退合计 16、证明 32 MiB。原有 handoff v1–v4 保持各自协议；共享的升级发布校验同时服务已恢复 V3 资格。

原 53525 检查发现一个真实缺陷：已完成回退的 completion 被删除后，重复 rollback 会重建它。v5 改为依次持久化回退决定、不可写的 `reactivating` 机器记录、绑定预定 active 记录的 completion，最后 CAS 发布 active。pending 可由原操作明确继续；active 缺原 completion 必须拒绝，不能重造历史证据。旧 v1/v3 回调与顺序契约没有被顺带改写。
